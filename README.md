# mateusands.github.io

Portfólio de Mateus Andrade, desenvolvedor Full Stack e AI Engineer.

Site estático em HTML, CSS e JavaScript puro, sem build. Disponível em português, inglês e espanhol, com o idioma detectado pelo navegador.

- `index.html`: conteúdo em português
- `i18n.js`: textos em inglês e espanhol
- `script.js`: projetos, filtros, idioma, tema e navegação
- `style.css`: temas claro e escuro

Publicado em https://mateusands.github.io
